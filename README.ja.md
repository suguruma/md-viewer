# MD Viewer

[English README is here](README.md)

Windows向け(Node.jsが動く環境ならどこでも)のローカルMarkdownビューアー。単一の `.md` ファイル、またはフォルダ配下のノート一式を、ビルド不要・アカウント不要・クラウド不要で、ライブリロード・GFM対応・シンタックスハイライト・図表/数式レンダリング付きのサイトとして閲覧できる。基本は閲覧用のツールで、元のファイルに書き戻すのはタスクリストのチェックボックス操作とテキスト装飾ショートカットの2つだけ(それ以外は完全に閲覧専用)。

## 機能

- **単一ファイル/フォルダモード** — 1ファイルまたはツリー全体を、遅延展開サイドバー付きで開く
- **再起動不要のフォルダ切替** — 「フォルダを開く」ボタンで実行中のサーバーのルートを任意の絶対パスへ切替。次回ダブルクリック起動時も同じフォルダを自動的に開く
- **GitHub Flavored Markdown** — テーブル、タスクリスト、打ち消し線、自動リンク、脚注、生HTML
- **シンタックスハイライト** — [Shiki](https://shiki.style/) によるライト/ダーク二重テーマをレンダリング時に埋め込み
- **Mermaidダイアグラム**・**KaTeX数式** — いずれも構文エラー時にページ全体を壊さずエラー表示
- **絵文字ショートコード**(`:smile:`)をUnicode絵文字として標準で描画
- **フロントマターカード** — YAMLの `title`/`tags`/日付をドキュメント上部にバッジカードとして表示
- **ダーク/ライトモード** — 選択を保存、図表・コードブロックもテーマに追従
- **検索** — ページ内検索とフォルダ横断検索
- **見出しアウトライン** — スクロール連動ハイライト付き。広い画面では常設パネル、狭い画面ではスライドインドロワー
- **マインドマップ俯瞰表示** — 現在のドキュメントの見出し・リストを [Markmap](https://markmap.js.org/) でインタラクティブなマインドマップとして表示。ノードをクリックすると通常のプレビューの該当箇所へ戻る
- **タスクリストのチェックボックスをクリック操作可能** — チェックのオン/オフで元ファイルの `[ ]`/`[x]` を書き換える
- **テキスト装飾ショートカット** — 単一の段落・見出し内の平文を選択し、`Ctrl+Shift+X` で `~~打ち消し線~~`、`Ctrl+Shift+U` で `<u>下線</u>` を付与
- **ポップアウトプレビュー** — 現在のドキュメントを別ウィンドウ/タブで開き、2台目のモニタに表示。メインウィンドウとリアルタイムに同期(表示中ドキュメント・テーマ・マインドマップ表示)
- **フルキーボード操作** — 矢印キー・Home/End・Enter/Spaceでファイルツリーを操作
- **印刷対応** — PDF出力やハードコピー用の専用印刷スタイルシート
- **ライブリロード** — ファイル保存でブラウザがその場で更新
- **プラグイン拡張** — 設定ファイル経由でremark/rehypeプラグインを追加、本体コード変更不要

詳細な仕様(アーキテクチャ、HTTP API、セキュリティモデル、実測性能)は [docs/FEATURES.ja.md](docs/FEATURES.ja.md) を参照。

## ダウンロード(Windows、Node.js不要)

**[GitHub Releases](../../releases/latest)** から最新版を取得する。

| パッケージ | 内容 | 向いている用途 |
| --- | --- | --- |
| `md-viewer-portable-win-x64-vX.Y.Z.zip` | 解凍してそのまま実行、インストール不要 | USBメモリ、管理者権限のないPC、お試し |
| `md-viewer-setup-win-x64-vX.Y.Z.exe` | ガイド付きインストーラー(ユーザー単位、管理者権限不要) | 常用、スタートメニュー/デスクトップ、任意で `mdv` コマンドをPATHに追加 |

いずれも未署名の個人配布ビルドのため、初回起動時にWindows SmartScreenが「WindowsによってPCが保護されました」と警告する場合がある。**「詳細情報」→「実行」**で起動できる。

**ポータブル版の使い方**: `mdv.exe` をダブルクリックすると同梱サンプルが開く。フォルダや `.md` ファイルをアイコンにドラッグ&ドロップすればそれを開く。ターミナルからは `mdv.exe "C:\path\to\notes"`。

**インストーラー版の使い方**: インストーラーを実行し、必要なら「PATHに追加」にチェック。スタートメニューまたはターミナル(`mdv <パス>`)から起動。

## ソースから実行(OS問わず)

Node.js 20.6 以上が必要。

```bash
git clone https://github.com/suguruma/md-viewer.git
cd md-viewer
npm install
npm start -- <フォルダまたはファイル>     # または: npm run sample
```

### CLIオプション

```
mdv [パス] [オプション]

  パス            表示する .md ファイル、またはフォルダ(省略時: カレントフォルダ)

  -p, --port N    ポート番号(既定 8931。使用中なら自動で+1)
      --host H    バインド先アドレス(既定 127.0.0.1)。名前を指定した場合は、その名前も Host として受け付ける
      --allowed-host NAME
                  この名前(PC 名など)でのアクセスも許可する(複数指定可)。localhost と IP アドレスは常に
                  許可され、それ以外の Host ヘッダーの要求は拒否される
      --no-open   起動時にブラウザを自動で開かない
      --poll      ポーリングでファイル監視(一部のクラウド同期フォルダ等で)
  -h, --help      ヘルプを表示
```

## 使い方

| 操作 | 方法 |
| --- | --- |
| ファイル切替 | サイドバーのツリーをクリック、またはフォーカスして `↑`/`↓`/`→`/`←`/`Home`/`End`/`Enter` |
| 別のフォルダを開く | サイドバー上部の「フォルダを開く」ボタン(絶対パスを入力) |
| ページ内検索 | ツールバーの検索欄(ショートカット `/`)。`Enter`/`Shift+Enter` で巡回、`Esc` でクリア |
| フォルダ横断検索 | サイドバーの検索欄(2文字以上)。結果クリックで該当ファイルを開きハイライト |
| 見出しへジャンプ | アウトラインパネルをクリック(狭い画面ではツールバーのボタンから開く) |
| マインドマップ表示 | ツールバーのマインドマップボタン。ノードをクリックするとプレビューの該当箇所へ戻る |
| タスクの完了/未完了切替 | チェックボックスをクリック(元ファイルの `[ ]`/`[x]` を書き換える) |
| 選択テキストの装飾 | 単一の段落・見出し内でテキストを選択し `Ctrl+Shift+X`(打ち消し線)または `Ctrl+Shift+U`(下線) |
| プレビューを別ウィンドウで開く | ツールバーのポップアウトボタン。もう一度クリックする(またはウィンドウを閉じる)とメイン側の表示に戻る |
| テーマ切替 | 右上のボタン |
| コードのコピー | コードブロックにマウスを乗せて「コピー」 |
| 印刷/PDF出力 | ブラウザの印刷機能。専用スタイルシートがUIを自動的に非表示にする |

相対リンク(`./other.md`、`../index.md#見出し`)はビューア内遷移になり、相対パスの画像はそのまま表示される。

## プラグインによる拡張

レンダリングは [unified](https://unifiedjs.com/)(remark/rehype)パイプラインで行われる。プロジェクトルートの `md-viewer.config.mjs` を編集するだけでプラグインを追加できる。**アプリ本体のコード変更は不要**。

```js
// md-viewer.config.mjs
import remarkGithub from 'remark-github'   // npm install remark-github

export default {
  remarkPlugins: [[remarkGithub, { repository: 'owner/repo' }]],
  rehypePlugins: [rehypeExternalLinksNewTab],  // 既定で同梱
  shiki: {},                                    // テーマ名の上書きもここで
}
```

絵文字ショートコード(`:smile:`)は `remark-emoji` により設定不要で標準搭載済み。設定変更の反映にはサーバーの再起動が必要。ユーザープラグインは組み込み処理すべての後、HTML出力の直前に実行される。

## 制限事項(設計上の判断)

- 2MBを超えるファイルはプレーンテキスト表示(ハイライト・数式なし)。最悪時のレイテンシを抑えるため
- フォルダ横断検索は単純な部分一致のみ。正規表現・索引なし
- HTMLサニタイズなし(`rehype-raw` が生HTMLを許可)。**利用者自身のローカルファイル**を閲覧する前提で既定は `127.0.0.1` バインド。信頼できないMarkdownを開く場合は設定ファイル経由で `rehype-sanitize` を追加すること
- 「フォルダを開く」機能は許可リストなしでOSユーザーが読み取れる任意のディレクトリへサーバーのルートを切り替えられる。信頼できないネットワークで `127.0.0.1` 以外にバインドすべきでない理由がもう一つ増えたことになる
- すべての HTTP リクエストと WebSocket 接続で、まず次を検査する。`Host` ヘッダーが `localhost`・IP アドレス・`--allowed-host` で指定した名前のいずれかであること、ブラウザが `Origin` ヘッダーを付けたときは `Host` と一致すること。これで、Web ページが DNS リバインディングや他サイトからの要求でローカルのサーバーに到達するのを防ぐ(ループバック限定のバインドだけでは防げない)。その代わり、別の名前(例: `http://my-pc:8931/`)でのアクセスは、`--allowed-host my-pc` を付けて起動しない限り `403` で拒否される
- 汎用エディタではない。書き込みが発生するのはチェックボックスのオン/オフと2つの装飾ショートカットのみで、いずれも書き込み範囲を厳しく限定している。サーバーは書き込み前に対象位置の原文が期待通りかを必ず検証し、一致しなければ書き込まずに拒否する。自由な文章編集は引き続きお使いのテキストエディタが必要。装飾ショートカットは単一の段落・見出し内でのみ有効で、複数ブロックにまたがる選択や、強調・リンク・数式などを含み原文と厳密一致しない選択は、画面上の通知のみで書き込みをスキップする
- マインドマップ表示は閲覧・移動専用。マインドマップ上でのノード直接編集はできない
- ポップアウトプレビューが同期するのは「メインウィンドウが今表示しているファイル・テーマ・マインドマップ表示」のみ(メイン→ポップアウトの一方向)。スクロール位置やページ内検索の状態は同期しない。そもそもこのアプリにはエディタ画面がないため、ライブ入力中のテキストを同期する対象自体が存在しない
