# 使い方のヒント

サブフォルダ内のファイルです。ツリーの階層表示と相対リンクの解決を確認できます。

## キーボードショートカット

| キー | 動作 |
| --- | --- |
| `/` | ページ内検索へフォーカス |
| `Enter` / `Shift+Enter` | 次 / 前の一致へ移動 |
| `Esc` | 検索をクリア |

## リンクの動き

- ビューア内遷移(親フォルダへの相対リンク): [トップへ戻る](../index.md)
- 見出しアンカー付きリンク: [数式ページの行列セクション](../math.md#行列)
- さらに深い階層へ: [アーカイブのメモ](archive/old-memo.md)

## 検索のヒント

- サイドバー上部の入力欄は**全ファイル横断検索**(2文字以上)
- ツールバーの入力欄は**表示中ページ内の検索**
- 横断検索の結果をクリックすると、そのファイルを開いて語をハイライトします
